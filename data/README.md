# Data

This project uses the **Netflix Movies and TV Shows** dataset from Kaggle.

- **Link:** https://www.kaggle.com/datasets/shivamb/netflix-shows
- **License:** CC0: Public Domain
- **File:** `netflix_titles.csv` (~3.4 MB, 8,807 rows, 12 columns)

## Description

Each row is one movie or TV show available on Netflix as of 2021, with its
type, title, director, cast, country, date added, release year, rating,
duration, genres (`listed_in`), and a short description.

## How to download

1. Sign in to Kaggle (a free account is required).
2. Open the link above and click **Download**.
3. Unzip the download and move `netflix_titles.csv` into this `data/` folder.

The final path should be `data/netflix_titles.csv`.
The data file is ignored by Git and should not be committed.
